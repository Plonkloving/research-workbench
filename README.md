# 科研工作台本地网页版

一个浅量、私密的科研灵感与资料工作台。灵感、便利贴、标签、任务和截图均分类保存在本地文件中。

## 首次安装

需要 Windows、Python 3、Node.js 22 或更高版本。克隆仓库后，在 PowerShell 中运行一次：

```powershell
cd web
npm install
```

以后双击 `打开科研工作台.vbs`，页面会自动在默认浏览器中打开。

## 本地数据

所有数据分类保存在当前目录的 `科研工作台数据` 文件夹：

- `灵感/ideas.json`
- `便利贴/notes.json`
- `标签/tags.json`
- `任务/tasks.json`
- `截图/index.json` 与 `截图/图片/`
- `设置/settings.json`

备份时直接复制整个 `科研工作台数据` 文件夹即可。建议关闭网页后再手动编辑 JSON 文件。

## 运行说明

- 网页仅监听本机地址，不对局域网或互联网开放。
- 首次打开可能需要等待数秒。
- 浏览器页面使用 `http://localhost:8765`，文件接口使用 `127.0.0.1:8766`。
- 页面记录不会写入浏览器存储，也不会上传到任何站点。
- `科研工作台数据` 已被 Git 忽略；仓库只包含可公开查看的示例数据。
